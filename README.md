## 📌 Sobre o projeto

O **Jogo do Número Secreto** é uma aplicação desenvolvida para praticar os primeiros conceitos de programação com **JavaScript**.

O objetivo do jogo é descobrir um **número secreto gerado aleatoriamente pelo sistema**.

Durante as tentativas, o programa compara o número informado pelo jogador com o número secreto e fornece orientações até que o valor correto seja encontrado.

> Este projeto representa uma das minhas primeiras aplicações práticas durante minha formação em programação, servindo como base para o desenvolvimento dos projetos mais avançados presentes no meu portfólio.

## 🎮 Como funciona

O fluxo principal da aplicação é:

```text
Início do jogo
      ↓
Geração do número secreto
      ↓
Usuário informa um número
      ↓
Sistema compara os valores
      ↓
Número correto?
   ↙       ↘
 Não       Sim
 ↓          ↓
Nova       Vitória
tentativa
```

O jogador recebe orientações durante as tentativas até descobrir o número escolhido pelo sistema.
